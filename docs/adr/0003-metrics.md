# ADR 0003: 방문자와 전환율 정의

- 상태: 승인
- 날짜: 2026-09-09

## 결정

방문은 배포 링크 페이지 로드마다 기록한다. 순 방문자는 브라우저 로컬 저장소에 생성한 익명 UUID의 고유 개수다. 전환율은 `신청 수 / 순 방문자 수 × 100`이며 방문자가 없으면 0이다.

## 이유

로그인 없는 공개 폼에서 개인정보를 추가 수집하지 않고 재방문을 구분할 수 있다.

## 결과

저장소 삭제, 다른 브라우저, 차단된 저장소는 새로운 방문자로 집계된다. 봇 필터링과 중복 신청 제한은 과제 범위에서 제외한다.
