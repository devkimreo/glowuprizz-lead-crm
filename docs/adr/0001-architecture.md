# ADR 0001: 단일 Node 애플리케이션과 PostgreSQL

- 상태: 승인
- 날짜: 2026-09-09

## 결정

관리자 UI, 공개 폼 호스트, REST API를 하나의 Express 애플리케이션으로 구현하고 PostgreSQL에 관계형 데이터를 저장한다. Docker Compose가 앱과 DB를 함께 실행한다.

## 이유

3일 과제의 핵심 흐름을 적은 운영 구성 요소로 재현할 수 있고, 평가자가 한 명령으로 실행할 수 있다. PostgreSQL의 JSONB는 임의 HTML 폼 필드를 보존하면서 캠페인·채널 관계를 정규화할 수 있다.

## 결과

수평 확장 시 세션과 데이터는 이미 DB에 있으므로 앱을 무상태로 복제할 수 있다. 파일 원문도 현재는 DB에 저장하며, 대용량 파일 요구가 생기면 객체 스토리지로 이전한다.
